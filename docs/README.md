## The short version

- **Pasting repairs broken Markdown.** For example, a table copied from a chat assistant arrives as `\| a | b |`, and Formiqo pastes it as a working table. If what you paste is already fine, Formiqo does nothing.
- **Commands tidy whole notes or selections.** Search for *Formiqo* in the command palette.
- **Reading View looks cleaner.** Tables, code, headings, lists and quotes are styled, and Formiqo follows your theme.
- **Your content is protected.** Code, math, frontmatter, callouts, HTML, comments and wikilinks are never rewritten. Every change can be undone with one **Undo**.
- **Everything happens on your device.** No network, no tracking, no AI services.
